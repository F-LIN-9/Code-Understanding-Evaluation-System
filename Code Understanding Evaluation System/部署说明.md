# 部署与使用说明

## 1. 环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11、Linux、macOS |
| Python | 3.9 及以上（仅用标准库，无需 pip 安装） |
| 浏览器 | Chrome / Edge / Firefox 等现代浏览器 |
| 磁盘 | 约 1 MB（不含数据库增长） |

不需要 Node、JDK、数据库服务，数据库为 SQLite 单文件（`data/codeassess.db`）。

## 2. 启动

```bash
cd 代码理解测评系统
python run.py                     # http://127.0.0.1:8765
python run.py --port 9000         # 指定端口
python run.py --host 0.0.0.0      # 允许局域网访问（课堂测评用）
```

启动后终端会打印访问地址、数据库路径以及当前的大模型状态（在线 / 离线规则模式）。

> 若 8765 端口被占用，换一个端口即可。Windows 防火墙首次拦截时需允许 Python 访问网络。

## 3. 课堂使用流程

1. 教师在实验室机器启动服务，`--host 0.0.0.0`，学生机用 `http://<教师机IP>:8765` 访问。
2. 学生在"我的代码"提交本次作业的核心代码，选择课程并填写知识点。
3. 学生（或教师）点击"生成测评题"，系统产生 5—8 道候选题，状态为**待审核**。
4. 教师在"题目审核"中逐题查看：**通过 / 修改 / 删除**；全部处理完才能"发布"。
5. 发布后学生在"待测测评"开始作答，页面显示剩余时间（限时由创建测评时指定）。
6. 交卷后系统立即给出建议分与分项反馈，状态为"已评分"。
7. 教师在"成绩复核"中逐题调整分数并保存，状态变为"已复核"，统计随之更新。
8. 在"统计"页查看四类任务得分率、知识点掌握情况与学生排名，用于教学调整。

## 4. 数据与备份

- 全部数据在一个文件里：`代码理解测评系统/data/codeassess.db`，直接复制即为备份。
- 重置演示数据：删除该文件后重新启动，或执行 `python run.py --reset-demo`。
- 操作日志保存在 `audit` 表，教师可在首页"最近操作"查看，便于追溯审核过程。

## 5. 大模型配置

推荐用环境变量（避免密钥写入文件）：

```powershell
$env:CODEASSESS_LLM_BASE  = "https://api.deepseek.com/v1"
$env:CODEASSESS_LLM_KEY   = "sk-xxxx"
$env:CODEASSESS_LLM_MODEL = "deepseek-chat"
```

也可写入 `data/config.json`（字段：`base_url`、`api_key`、`model`、`timeout`）。
配置生效后，页面顶部状态由"离线规则模式"变为"大模型已接入"；出题时若接口超时或返回
不合规，系统会自动退回规则引擎，不影响测评流程。

> 提示：大模型输出会经过结构校验（题型、选项、行号范围、评分要点），不合规的题目直接丢弃，
> 不足 4 道时整份测评改用规则引擎生成。

## 6. 部署到 Render（云端）

代码已适配 Render：启动时自动读取 `PORT` 环境变量并监听 `0.0.0.0`，无需改动代码。

**第一步：推送到 GitHub**

```bash
git remote add origin https://github.com/<你的用户名>/codeassess.git
git push -u origin main
```

**第二步：在 Render 创建 Web Service**

1. 登录 <https://dashboard.render.com> → `New` → `Web Service`
2. 连接 GitHub 仓库，Render 会自动读取仓库根目录的 `render.yaml`
3. 若手动填写：Runtime 选 `Python 3`，Build Command 填 `pip install -r requirements.txt`，
   Start Command 填 `python run.py`，Health Check Path 填 `/api/health`
4. 在 `Environment` 里添加环境变量（见下表），然后 `Create Web Service`

**第三步：环境变量**

| 变量名 | 必填 | 示例值 | 说明 |
| --- | --- | --- | --- |
| `CODEASSESS_LLM_BASE` | 是 | `https://api.deepseek.com/v1` | 兼容 OpenAI 的接口地址，不带 `/chat/completions` |
| `CODEASSESS_LLM_KEY` | 是 | `sk-xxxx` | 密钥，只在 Render 后台保存，不要写进仓库 |
| `CODEASSESS_LLM_MODEL` | 是 | `deepseek-chat` | 模型名 |
| `CODEASSESS_DATA_DIR` | 否 | `/opt/render/project/src/data` | 数据库目录，默认已在 `render.yaml` 中设置 |
| `PYTHON_VERSION` | 否 | `3.11.9` | 已在 `render.yaml` 中设置 |

> **注意**：Render 免费实例的文件系统是临时的，每次重新部署或重启后 `codeassess.db` 会重置，
> 系统会自动重新建库并写入演示数据。需要持久化请挂载 Disk（付费实例），
> 并把 `CODEASSESS_DATA_DIR` 指向挂载路径（如 `/var/data`）。

部署成功后访问 `https://<服务名>.onrender.com`，用教师账号 `liyuejun` 登录验证；
访问 `/api/health` 应返回 `{"ok": true, "data": {"app": "代码理解测评系统", "ok": true}}`。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 打开页面空白 | 确认访问的是 `http://127.0.0.1:8765`（带端口），并查看终端是否报错 |
| 中文显示为乱码（终端） | 设置 `$env:PYTHONIOENCODING="utf-8"` |
| 提示"没有权限执行该操作" | 当前账号角色不符：审核/发布/复核仅教师可用 |
| 提示"还有 N 道候选题未审核" | 发布前必须把每道题处理为通过或删除 |
| 学生重复作答被拒 | 同一测评只允许提交一次，用于课堂限时场景 |
| 端口被占用 | `python run.py --port 9000` |
